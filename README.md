# Movie Recommendation Database | PostgreSQL & SQL

**Arizona State University | CSE 511: Data Processing at Scale | Graduate Coursework**

## Overview

Built and queried a relational movie recommendation database in PostgreSQL as part of two graduate-level data-processing assignments. The project covered database setup, relational schema design, data loading, and SQL queries to explore relationships among users, movies, and ratings.

## What I Implemented

- **Database Construction:** Created and populated relational tables for users, movies, and ratings using PostgreSQL.
- **Relational Queries:** Connected tables using SQL joins, filtering, and nested queries.
- **Analytical SQL:** Used aggregate functions, `GROUP BY`, and `HAVING` to analyze and summarize ratings.
- **Parameterized Queries:** Worked with SQL input parameters in PostgreSQL.
- **Testing:** Validated queries using automated course tests.

## Tools & Technologies

PostgreSQL · SQL · psql · Relational Database Design · Joins · Subqueries · Aggregation · Grouping · Filtering

## What I Learned

Strengthened my understanding of relational database organization, SQL query construction, and analytical data processing. Gained hands-on experience configuring PostgreSQL, working with related tables, and validating database queries.

## Future Improvements

Potential extensions include database indexing, query optimization with `EXPLAIN`, advanced analytical queries, and Python integration for automated data loading.
